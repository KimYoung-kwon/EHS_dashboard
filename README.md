# AX·공장자동화 과제 현황판

부서별 과제 등록 엑셀(01~09 구분)을 올리거나 웹에서 직접 입력해 과제 진행과 FTE·KPI 실적을 팀·그룹 단위로 관리하는 사내용 대시보드입니다. 내 PC에서 `serve.py`를 실행하면 사내 다른 사람이 `http://12.82.113.36:8765`로 접속해 같은 데이터를 보고, 비밀번호 없이 바로 입력·수정·엑셀 반영을 할 수 있습니다. 저장할 때마다 직전 상태가 `data/backup`에 남아 잘못 지운 데이터를 되살릴 수 있습니다.

## 실행 (Windows PowerShell)

Python 3.8 이상이면 되고 추가 설치는 없습니다. 그래프·엑셀·글꼴 라이브러리를 `vendor` 폴더에 넣어 두어 인터넷이 막힌 사내망에서도 동작합니다.

1. 내려받기
   ```powershell
   cd D:\
   git clone -b main https://github.com/KimYoung-kwon/ehs_dashboard.git
   cd D:\ehs_dashboard
   ```
   이미 받은 적이 있으면 `cd D:\ehs_dashboard` 후 `git pull`.
2. 서버 켜기
   ```powershell
   py serve.py
   ```
   - 창에 `사내 다른 PC에서: http://12.82.113.36:8765`가 보이면 정상입니다. 창을 닫거나 Ctrl+C를 누르면 서버가 꺼집니다.
   - 포트 변경: `py serve.py --port 8766` (8765를 다른 프로그램이 쓰는 경우)
   - 보기만 허용: `py serve.py --readonly` (입력·수정·업로드를 막고 싶을 때)
3. 방화벽 열기 (관리자 권한 PowerShell, 처음 한 번)
   ```powershell
   New-NetFirewallRule -DisplayName "AX Dashboard 8765" -Direction Inbound -Protocol TCP -LocalPort 8765 -Action Allow
   ```
   권한이 없으면 IT에 "TCP 8765 인바운드 허용"을 요청합니다.
4. 접속 확인: 내 PC는 `Start-Process http://localhost:8765`, 다른 PC는 `Test-NetConnection 12.82.113.36 -Port 8765`에서 `TcpTestSucceeded : True`.
5. 상시 운영(선택)
   ```powershell
   powercfg /change standby-timeout-ac 0
   $s = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\AX Dashboard.lnk")
   $s.TargetPath = "D:\ehs_dashboard\start.bat"; $s.WorkingDirectory = "D:\ehs_dashboard"; $s.Save()
   ```
   절전 해제와 로그인 시 자동 실행입니다. PC가 꺼지거나 잠들면 다른 사람도 접속할 수 없습니다.

12.82.113.36은 사설 IP 대역(10.x, 172.16~31.x, 192.168.x)이 아니므로, 회사 밖에서 8765 포트로 들어오는 접속이 회사 방화벽에서 막혀 있는지 IT에 확인해 주세요.

## 데이터 입력

| 방법 | 동작 |
| --- | --- |
| 상단 **+ 과제 추가** | 01~09 구분별 입력 패널. 자동 계산 항목(연간 공수, Baseline·발굴 FTE, KPI 발굴 효과)은 입력 즉시 계산, 비어 있는 필수·조건부 필수 항목은 빨갛게 표시 (비어 있어도 저장은 가능) |
| 과제 상세의 **수정·삭제** | 어느 화면에서든 과제를 누르면 상세 창 → 수정 / 삭제. 엑셀로 올린 과제도 같음 |
| 상단 **엑셀 업로드** | 미리보기에서 팀별 추가·변경·삭제 건수 확인 후 **반영**. 엑셀에 있는 팀의 과제만 엑셀 내용으로 교체하고 다른 팀은 그대로 둠. 과제명(중분류)이 같으면 같은 과제로 봄 |
| 과제 관리 › **엑셀 형식** | 저장된 데이터를 업로드 양식과 같은 컬럼 순서로 웹에서 그대로 보기 |
| 상단 **엑셀 내려받기** | 현재 데이터를 업로드 양식과 같은 컬럼 순서로 저장. 백업이나 부서 회신용 |

- 처음 저장하기 전에는 예시 데이터(가상)가 보이며, 첫 업로드나 과제 추가 시 사라집니다.
- 비밀번호는 묻지 않습니다. 입력 패널 아래 **입력자** 칸에 이름을 적으면 변경 이력에 남고, 다음부터 자동으로 채워집니다(비우면 접속 PC의 IP로 기록).
- 엑셀에 `우선순위` 컬럼(상/중/하)을 추가하면 함께 반영됩니다. 컬럼이 없으면 기존 우선순위를 유지합니다.
- 두 사람이 같은 시점에 수정하면 나중 사람에게 "다른 사람이 먼저 수정했습니다"가 뜨고 최신 데이터를 다시 불러옵니다.
- 다른 사람이 저장한 내용은 열어 둔 화면에 20초 안에 반영됩니다.

## 화면 구성

| 탭 | 보는 것 |
| --- | --- |
| 종합 현황 | 핵심 숫자 5개(누르면 상세 창) · 조직별 FTE 목표 달성(두 칸) · FTE 효과 흐름 · 누적 목표 대비 실적 · 단계별 과제 · 경영관리지표별 · 우선 관리 과제 |
| 과제 맵 | 팀 › 그룹별로 묶은 과제 박스 한 장. 박스 색은 상태(지연·목표 미달·정상 진행·완료·착수 전), 박스 안 막대는 확보÷발굴 진척률과 기준일 목표, 점 5개는 진행단계 |
| 조직별 현황 | 팀별 실적표(그룹 펼치기, 단계 분포, 달성률, 전주 대비, 8주 추이, 지연·우선 상·경보 건수) · 조직별 우선 과제 카드(팀당 5건) |
| 과제 관리 | 검색·정렬·단계 필터 표 / 엑셀 형식 전체 컬럼 보기 |
| 추진 일정 | 팀 > 그룹별 계획 대비 실적 간트 |
| 데이터 점검 | 입력 규칙 점검 결과 · 변경 이력(누가·언제·무엇을) |

상단의 팀·그룹·과제구분·우선순위·기준일 필터는 모든 탭에 함께 적용됩니다. 팀을 고르면 조직 단위가 그 팀의 그룹으로 바뀝니다.

- **마우스를 올리면**: 막대·추이선·단계 분포·일정 도형마다 색과 선의 의미, 실제 수치가 뜹니다.
- **누르면**: 숫자 카드, 조직 행, 효과 흐름 막대, 단계 막대, 지표 행, 누적 목표 그래프의 월, 과제 박스가 모두 관련 데이터를 상세 창으로 띄웁니다. 창 안에서 다시 누르면 위에 쌓이고 **← 이전**으로 돌아갑니다. Esc나 바깥을 누르면 닫힙니다.

## 지표 정의

| 지표 | 계산 |
| --- | --- |
| 기준일 목표 | 과제별로 기준일까지 도래한 가장 늦은 단계(S5→S4→S3)의 누적 확보 목표 FTE |
| 달성률 | 확보 FTE ÷ 기준일 목표. 양호 100% 이상 · 주의 80~100% · 미흡 80% 미만 |
| 전주 대비 | 현재 확보 FTE − 지난주 일요일 시점 확보 FTE |
| 8주 추이 | 최근 8주 각 일요일 시점의 확보 FTE(실선)와 기준일 목표(점선) |
| 경보 | 지연(현재 단계 목표일 경과) · 목표 미달(확보 < 기준일 목표의 80%) · 입력 누락(필수·조건부 필수 미입력) |
| 우선 과제 순서 | 우선순위(상→중→하→미지정) → 경보 수 → 발굴 FTE |
| 실현 인원 | 팀내 재배치 + 신규라인 재배치 + 기타 실현(휴직/파견 등) |

- 전주 대비와 8주 추이는 서버가 저장할 때마다 남기는 **주간 스냅샷**(`data/history`)으로 계산합니다. 실제 데이터는 첫 저장 다음 주부터 전주 대비 값이 나오고, 8주가 지나야 추이가 다 채워집니다.
- 진행단계(S1~S5)는 "현재 수행 중인 단계"로 보고, 그 단계의 목표일이 기준일보다 이르면 지연으로 표시합니다. S5는 실적 종료일이 있으면 완료입니다.
- `[자동]` 항목은 엑셀 값 대신 양식의 식으로 다시 계산합니다: 연간 공수 = 건당 1인 소요시간 × 연간 건수 × 건당 투입인원, Baseline FTE = AS-IS 연간 공수 ÷ 2,000, 발굴 FTE = (AS-IS − TO-BE 연간 공수) ÷ 2,000.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `index.html`, `assets/` | 화면 (예시 데이터는 `index.html` 안에 포함) |
| `serve.py`, `start.bat` | 사내 공유용 서버와 Windows 실행 파일 |
| `data/` | 저장 데이터(`store.json`), 주간 스냅샷(`history/`), 변경 이력(`changes.jsonl`), 저장 직전 백업(`backup/`, 최근 200개). GitHub에 올라가지 않고, 서버가 외부에 내려주지도 않음 |
| `vendor/` | d3 7.9.0, SheetJS 0.18.5, Pretendard 글꼴과 각 라이선스 |
| `sample/` | 예시 데이터(가상 6개 팀 × 2개 그룹, 36개 과제)의 엑셀·JSON·주간 스냅샷 |
| `tools/generate_sample.py` | 예시 데이터 생성기 (`pip install openpyxl` 필요) |

백업은 `data` 폴더를 통째로 복사하면 됩니다. 잘못 지운 데이터를 되살리려면 서버를 끄고 `data/backup`에서 원하는 시점의 `store-날짜-시각.json`을 `data/store.json`으로 복사한 뒤 다시 켭니다.
