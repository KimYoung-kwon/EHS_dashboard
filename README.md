# AX·공장자동화 과제 현황판

부서별로 받은 과제 등록 엑셀(01~09 구분, 74개 컬럼)을 올리면 과제 진행 경과와 FTE·KPI 실적을 한 화면에서 보여 주는 단일 HTML 대시보드입니다. 서버나 설치가 필요 없고, `index.html`을 브라우저로 열면 예시 데이터 34건이 바로 표시됩니다. 그래프(d3)와 엑셀 읽기(SheetJS) 라이브러리를 cdnjs에서 불러오므로 인터넷 연결이 필요합니다.

## 파일 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 대시보드 본체. 예시 데이터가 `<script id="sample-data">` 안에 들어 있음 |
| `sample/AX_과제_예시.xlsx` | 업로드 양식과 같은 컬럼 순서(1행 구분, 2행 컬럼명, 3행부터 데이터)의 예시 파일 |
| `sample/tasks.json` | 같은 예시 데이터의 JSON |
| `tools/generate_sample.py` | 예시 데이터 생성기. 실행하면 위 세 파일을 다시 만듦 (`pip install openpyxl` 필요) |

## 엑셀 업로드 규칙

대시보드는 시트에서 `과제명(중분류)`가 들어 있는 행을 컬럼명 행으로 보고, 그 아래 행을 과제 데이터로 읽습니다. 그래서 컬럼명 위에 구분 행이나 안내 문구가 몇 줄 있어도 상관없습니다. 컬럼명은 앞의 `*` 표시와 공백을 무시하고 비교하므로 `* 팀`과 `팀`은 같은 컬럼으로 인식합니다. 컬럼 순서는 달라도 되며, 인식하지 못한 컬럼명은 업로드 직후 안내 문구에 표시됩니다.

`[자동]` 항목(연간 공수 MH, Baseline FTE, 발굴 FTE, KPI 발굴 효과, KPI 단위)은 엑셀 값을 그대로 쓰지 않고 입력값으로 다시 계산합니다. 양식에 적힌 식과 같습니다: 연간 공수 = 건당 1인 소요시간 × 연간 건수 × 건당 투입인원, Baseline FTE = AS-IS 연간 공수 ÷ 2,000, 발굴 FTE = (AS-IS − TO-BE 연간 공수) ÷ 2,000, KPI 발굴 효과 = 개선방향이 감소면 AS-IS − TO-BE, 증가면 TO-BE − AS-IS. 엑셀 수식이 깨졌거나 값으로 붙여넣기가 안 된 파일이 와도 같은 숫자가 나오게 하려는 것입니다.

## 화면 구성과 그렇게 나눈 이유

상단에는 기준일·팀·과제구분 필터와 업로드 버튼을 두고, 그 아래 한 문장 요약(발굴 대비 확보, 기준일 목표 대비 달성률, 지연 건수)을 둡니다. 보고받는 사람이 표를 읽기 전에 "목표 대비 잘 가고 있는가, 막힌 과제가 몇 개인가"를 먼저 알 수 있게 하려는 배치입니다. 필터는 네 탭 모두에 함께 적용됩니다.

**종합 현황** 탭은 숫자 카드 5개(등록 과제, 발굴 FTE, 확보 FTE, 실현 인원, 일정 지연)로 시작합니다. 확보 FTE 카드에는 "기준일 목표 대비 %"를 색으로 표시합니다(100% 이상 초록, 80% 이상 주황, 그 미만 빨강). 그 아래 FTE 효과 흐름은 Baseline → 발굴 → 확보 → 실현을 같은 축의 막대로 이어 그려, 어느 구간에서 효과가 빠지는지(발굴은 많은데 확보가 적은지, 확보는 됐는데 재배치가 안 됐는지)를 보여 줍니다. 진행단계별 과제는 S1~S5 막대로 과제가 어느 단계에 몰려 있는지와 단계별 지연 건수를 보여 주고, 막대를 누르면 그 단계의 과제 목록으로 이동합니다. 누적 확보 목표 대비 실적 그래프는 각 과제의 S3·S4·S5 목표일정과 누적 목표 FTE를 월별로 쌓은 계단선 위에 기준일 현재 확보 FTE를 점으로 찍어, 앞으로 몇 월에 목표가 얼마나 늘어나는지도 함께 보여 줍니다. 팀별 막대를 누르면 화면 전체가 그 팀으로 필터되고, 경영관리지표(P/Q/C/D/S/M)별 과제 수와 P 외 지표의 KPI 확보 진척을 따로 보여 줍니다. 마지막 관리 필요 과제 표는 지연·확보 부진·필수 항목 누락 과제를 지연 일수가 긴 순서로 모읍니다.

**추진 일정** 탭은 팀별로 묶은 간트 차트입니다. 옅은 막대가 계획 기간, 진한 막대가 실적 기간(완료 초록, 지연 빨강, 정상 파랑), 마름모가 S1~S5 목표일정이며, 목표일을 넘긴 현재 단계는 빨간 테두리로 표시합니다.

**과제 목록** 탭은 검색·정렬·단계 필터가 되는 전체 표이고, 행을 누르면 그 과제의 엑셀 입력값 전체를 01~09 구분 그대로 보여 주는 상세 패널이 열립니다. 비어 있는 필수 항목은 "미입력"으로 빨갛게 표시됩니다.

**데이터 점검** 탭은 양식의 입력 규칙을 업로드한 행마다 검사합니다. 공통 필수 누락, 조건부 필수(KPI 기타 → 기타 KPI명·단위, S1~S4 → 다음 단계 추진계획, P 외 지표 → AS-IS/TO-BE·근거·S3~S5 KPI 목표, 확보·실현 효과 입력 → 산정근거, PKMS 등록 → 과제명, S2 이상 → 실적 시작일), 앞뒤 관계(S1~S5 목표일 순서, S3→S4→S5 누적 목표가 줄지 않는지, 확보 FTE가 발굴 FTE를 넘지 않는지, 실현 인원이 확보 FTE를 넘지 않는지)를 봅니다. 여러 부서에서 받은 파일을 합칠 때 가장 손이 많이 가는 일이 빠진 칸을 되묻는 일이어서, 이 탭을 그대로 회신 목록으로 쓸 수 있게 했습니다.

## 지표 정의와 가정

| 지표 | 계산 |
| --- | --- |
| 기준일 누적 목표 | 과제별로 기준일 이전에 도래한 가장 늦은 단계(S5 → S4 → S3 순)의 누적 확보 목표 FTE. 아직 S3 목표일 전이면 0 |
| 목표 대비 달성률 | 확보 FTE 합 ÷ 기준일 누적 목표 합 |
| 확보 부진 | 기준일 누적 목표가 있는데 확보 FTE가 그 80% 미만인 과제 |
| 실현 인원 | 팀내 재배치 + 신규라인 재배치 + 기타 실현(휴직/파견 등) 인원 |
| 일정 지연 | 현재 진행단계의 목표일정이 기준일보다 이른데 아직 그 단계에 있는 과제. S5는 실적 종료일이 입력되면 완료로 봄 |
| KPI 확보 진척 | KPI 확보 효과 ÷ KPI 발굴 효과 (P 외 지표만) |

진행단계 값(S1~S5)은 "현재 수행 중인 단계"로 해석했고, 각 단계의 목표일정은 양식 설명대로 그 단계의 완료 목표일로 봅니다. 기준일은 업로드 시 오늘 날짜로 잡히며, 상단 기준일 칸에서 바꾸면 지연·누적 목표가 그 날짜 기준으로 다시 계산됩니다. 과제구분 값은 예시에서 `AX`와 `FA`(공장자동화)로 두었고, 실제 파일의 값이 다르면 필터 목록이 그 값으로 바뀝니다.

## 예시 데이터

`sample/`의 데이터는 실제 과제가 아니라 화면을 보여 주기 위해 만든 가상의 34개 과제(6개 팀)입니다. 일부 행에는 데이터 점검 탭을 보여 주기 위해 조건부 필수 항목을 일부러 비워 두었습니다. `python3 tools/generate_sample.py`로 다시 만들 수 있습니다.
