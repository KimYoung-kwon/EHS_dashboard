# data 폴더

부서에서 받은 과제 엑셀(.xlsx)을 이 폴더에 넣으면, `serve.py`로 띄운 현황판에 접속한 사람 모두가 그 데이터를 봅니다. 파일이 여러 개면 가장 최근에 수정된 파일 하나를 씁니다. 그래서 새 버전을 받으면 이름을 `AX_과제_2026-11.xlsx`처럼 바꿔 넣기만 하면 되고, 이전 파일은 지우지 않아도 됩니다(보관용으로 남겨 두면 됩니다).

현황판을 열어 둔 사람의 화면은 1분 안에 새 파일로 자동으로 바뀝니다. 엑셀에서 파일을 연 채로 두면 생기는 `~$`로 시작하는 임시 파일은 무시합니다.

이 폴더의 엑셀은 `.gitignore`에 걸려 있어 GitHub에 올라가지 않습니다(사내 과제 데이터가 외부 저장소로 나가지 않게 하려는 설정입니다).
