# data 폴더

`serve.py`가 저장하는 파일이 모이는 곳입니다. 직접 고치지 말고 화면에서 입력·업로드해 주세요.

| 파일 | 내용 |
| --- | --- |
| `store.json` | 현재 과제 데이터 |
| `history/2026-W43.json` 등 | 주간 스냅샷(그 주의 마지막 저장 상태). 화면의 전주 대비·8주 추이에 사용 |
| `changes.jsonl` | 변경 이력(일시, 입력자, 작업, 대상) |
| `backup/store-날짜-시각.json` | 저장 직전 상태(최근 200개). 되살리기: 서버를 끄고 원하는 파일을 `store.json`으로 복사 후 재시작 |

- 이 폴더는 `.gitignore`에 걸려 있어 GitHub에 올라가지 않고, 서버도 이 폴더의 파일을 접속자에게 내려주지 않습니다.
- 백업은 폴더 전체를 복사하고, 복원은 복사해 둔 파일을 다시 넣은 뒤 서버를 재시작하면 됩니다.
- 이전 버전에서 만든 `config.json`(편집 비밀번호)은 더 이상 쓰지 않으므로 지워도 됩니다.
